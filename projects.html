Pong-Champs (Demo)

About the Project

Developed as a collaborative project for the Imperative Functional Programming (PIF) course, Pong-Champs is a dynamic table tennis game. Inspired by the classic Pong, our team expanded the core mechanics to include free character movement, trajectory physics, and an energy system for special abilities and, of course, great sprites for our main characters and scenario.

Note: This C and Raylib build serves as a demo, as a full version is currently in development using Godot!


Technologies Used

  • C
  • Raylib
  • GCC / MinGW & Makefile

Key Learnings

This project was a deep dive into game programming fundamentals. Working alongside my teammates Arthur Vitorino and Juan Riquelme, I gained hands-on experience structuring modular C code, managing game states (Menus, Gameplay, and Victory conditions), and manipulating sprite animations.

Laço Favela

About the Project

Developed alongside a large party of developers and designers, Laço Favela is a full-stack web application built to support the G10 Favelas. Our overarching quest was to digitize and streamline the "Presidente de Rua" initiative, replacing outdated physical forms with a secure platform to manage donations and track data for vulnerable families.

For this campaign, I specialized as a backend engineer, constructing the core logic and database architecture, while also stepping into the frontend to make critical UI adjustments and ensure seamless integration.


Technologies Used

  • Python 3 & PostgreSQL (Backend)
  • JavaScript & React (Frontend)
  • HTML & CSS

Key Learnings

This project was a massive exercise in agile development and large-scale teamwork. I gained valuable experience managing complex sprints via Jira across different user roles (Admin, Presidente de Rua, and Morador). It solidified my ability to architect a robust backend capable of handling real-world social impact data while coordinating continuous deployments via Azure.

∄XIT

About the Project

Developed for the Mathematical Logic for Computing course, ∄XIT is a liminal horror puzzle game wrapped in an eerie, analog VHS aesthetic. The game translates abstract math into tangible gameplay: players navigate unsettling spaces—like an empty market, subway, bathroom, and classroom—by reading logical sentences on scattered papers and manipulating levers to match the propositions (e.g., lever up = A, lever down = ~A).

Working within a big team, I acted as one of the two core programmers, focusing heavily on building out the interactive logic systems and puzzle mechanics using Godot.


Technologies Used

  • Godot Engine
  • Free-to-use 3D Assets
  • Propositional Logic Algorithms

Key Learnings

This project was a fantastic exercise in translating theoretical computer science concepts into engaging, interactive mechanics. As a co-programmer, I honed my skills in Godot, managing state changes across multiple levels (from Lvl 0 to the Classroom). I also ensured the underlying code correctly evaluated the players' lever combinations against the required truth tables, all while helping maintain a tense, time-sensitive atmosphere where the "tape is running out".
